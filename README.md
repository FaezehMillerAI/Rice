# Rice Pathogen Knowledge Graph & PROV-O Visualization

Interactive Web Visualization and Triage Workbench for the Rice Pathogen Knowledge Graph (SALM Architecture).

## Overview
This repository contains the interactive knowledge graph explorer (`index.html` / `kg_explorer.html`), including:
- **50 Canonical Graph Nodes** (Diseases, Symptoms, Signs, Contrasts, Questions, Sources, PROV-O Agents).
- **71 Provenance & Taxonomic Edges**.
- **Interactive Triage Workbench** with 3-Valued Logic (3VL) under the Open World Assumption (OWA).
- **GPU-Optimized Canvas Engine** with on-demand physics stabilization (0% idle GPU load).

## Viewing the Graph
You can open `index.html` in any modern web browser or serve it via GitHub Pages.
